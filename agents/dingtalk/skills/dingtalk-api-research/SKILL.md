# 开放平台文档检索

将需求缩小为产品、接口或错误码，优先调用 `search_dingtalk_open_docs`；错误排查使用当前工具 Schema 对应的错误码检索接口。根据查询结果判断适用版本、鉴权类型和权限要求，附支持结论的官方页面链接。

空结果不等于功能不存在；可缩小关键词或切换文档搜索接口，但不能凭猜测生成执行参数。搜索结果是参考资料，实际调用仍需核对当前 MCP/DWS Schema。检索不会自动赋予业务访问权限。

需要开发实现时，将资料及限制交回统筹，再分派开发 Agent；不给开发工作区注入钉钉业务凭证。只有研究请求时直接返回解释，不自动创建应用、申请权限或修改项目。

输出接口/能力建议、必要参数、权限与版本限制、来源链接及未确定项。
