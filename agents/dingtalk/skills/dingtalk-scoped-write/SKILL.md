# 限定范围的办公写入

读取 [授权规则](../../../../docs/integrations.md)、[操作批准](../../../../docs/approvals.md) 与 [操作记录协议](../../../../docs/contracts.md)。MCP 安装/OAuth 授权只是连接条件。任务信息已明确时不重复询问业务信息；执行仍按 auto/ai/user 策略批准，user 模式必须展示具体操作给任务用户，不能自行批准。

1. 明确动作、目标 ID、内容、接收者、范围及时间。创建会议确认日期、时区和参与者；发送消息/邮件确认收件目标及内容；表格写入确认 Base/表或工作表/范围。
2. 从注册技能和清单取工具，检查当前 Schema 与实际业务权限。OA 的查询授权不能推导为同意/拒绝审批的授权；组织管理、权限变更和删除未列入当前常用工具，遇到明确需求交回统筹制定专项计划。
3. 修改前读取目标；新增前检查本次操作记录和关联对象。保存参数摘要、预期效果与幂等记录，按目标串行执行。
4. 按产品核验：文档读回内容；AI 表格逐记录确认；普通表格读回范围；待办读回详情；日程读回事件；消息/邮件保存回执及对象 ID。仅有创建回执时注明验证层级，不推断对方已收到/已读。
5. 群聊、视频会议、AI 印当前没有可用的只读验证工具。业务确需创建或生成时使用服务回执；缺少独立回读记为 `write_acknowledged`，不得称 `readback_verified`。不为健康检查而创建产物。

写入超时、响应矛盾或结果不明时返回 `REMOTE_STATE_UNKNOWN`；查询确认之前不换 MCP/DWS 重放。生成服务可能计费，先按任务已授预算和当前 Schema 判断；无法确认费用时返回所需信息。

输出目标引用、操作 ID、参数摘要、实际效果、验证层级与遗留问题。未知结果不能记作已完成。
