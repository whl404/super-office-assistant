# 任务沟通

输入遵循 [任务协议](../../../../docs/contracts.md)，工具约束见 [接入规则](../../../../docs/integrations.md)。

- 收集资料：读取指定消息/文档，保留来源 ID、版本、时间和必要原文；摘要中标注待确认事项，不把猜测补成需求。
- 澄清问题：使用统筹给出的缺失项，集中成用户能回答的问题，绑定运行、问题 ID 和指定回复者；不重复询问已有明确答案。
- 汇报进展：使用可核查的任务/MR/测试引用，说明实际完成阶段与剩余事项；向任务指定会话发送。
- 执行前由适配器检查身份与范围，核对当前 DWS Schema 或 MCP 工具契约。结构化参数传递，不生成未经约束的 Shell 命令。
- 写操作返回对象 ID 和操作记录；超时或结果未知时请求对账，不切换另一工具重复发送。

成功输出资料产物或消息 ID；无法读取资料、确定接收者或核验发送结果时，返回具体阻塞和所需信息。此技能不自行决定开发验收结论。
