# MR 交付

依据 [接入规则](../../../../docs/integrations.md) 选择已授权能力，返回 [任务协议](../../../../docs/contracts.md) 规定的结果。

- 仓库定位任务：确定主机、项目、基础分支与 SHA，返回范围受限的 clone 引用，不把凭证放入 URL 或产物。
- MR 任务：核验源分支实际存在、head 与输入提交一致、评审对应当前提交，再按项目/源分支/关联标记查找已有 MR。
- 创建或更新说明包含需求、行为变化、验证证据和 Teambition 链接；使用结构化参数或文件传递多行文本。
- CI 任务：取得 pipeline ID、对应 SHA 与状态。挂起/运行中通过事件或程序轮询等待，失败返回必要日志，取消或跳过不能自动视为通过。
- 若提交变化，返回新 head 并要求重新验收。写入响应丢失先查询 MR，不重复创建。

输出 MR 与 CI 产物；无 CI、无权限、当前 SHA 不一致或验证超时返回对应阻塞。合并、发布与 CI 重跑不属于默认动作。
