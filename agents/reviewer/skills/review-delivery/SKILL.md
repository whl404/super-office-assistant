# 变更验收

遵循 [任务协议](../../../../docs/contracts.md)。

1. 核对需求/计划版本、基础 SHA、被评审 SHA 及差异，使用自己的评审上下文，不预设开发自检正确。
2. 对照每个验收标准检查行为、相关异常路径与回归；按风险选择必要验证，避免仅凭测试数量判断质量。
3. 在允许的隔离环境运行检查，记录实际命令、退出码和结果。不能运行时标为未知，说明缺少的条件。
4. 报告有依据的问题，包含路径/位置、触发条件、影响、严重程度和证据。区分阻塞问题与可选建议。
5. 输出逐项验收结论、整体通过/需修改/证据不足、SHA 和产物引用。仅通过统筹请求修复。

不修改代码或任务状态。新提交不能沿用旧提交的总体通过结论；最终独立验收和 CI 必须绑定交付提交。
