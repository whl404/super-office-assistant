# 项目与任务查询

本项目使用钉钉网关的 `dingtalk-teambition` 服务。先发现当前用户参与的项目，再核对项目详情；已有任务链接可直接定位任务，保留任务与项目 ID。

- 查询任务前明确项目、执行人、时间和状态条件。需要 TQL 时依据实际工具契约生成，不假定所有项目字段通用。
- 查询统计需要遍历完整分页并去重；只取一页时说明范围。无权限、未开启进展功能与空结果分别报告。
- 状态以项目工作流真实返回为准。当前状态更新工具需要状态名，应从同项目状态查询结果取对应名称，不将设计中的状态 ID 强行作为参数。
- 写入核验对照本次预期字段，关注用户并发改动；不能为“修正统计”顺手更新任务。
- 任务结果附可访问链接 `https://www.teambition.com/task/{taskId}`，项目链接按工具实际返回提供。链接不能代替查询成功证据。

输出查询事实、来源、统计范围、完整性及限制。需要写入时向统筹提出动作请求，由任务同步技能执行。
