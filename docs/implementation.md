当前已补齐：18 项 MCP 与 DWS 接入、十项技能、六角色注册（GitLab 暂停）、95 个工具候选和五条工作流模板，附纯标准库配置校验/装配脚本及行为检查。

新增 [异步执行器](executor.md)：已实现单次操作的精确授权匹配、参数验证入口、业务错误分类、限流与只读重试、工具调用预算、SQLite 操作记录、目标写锁、取消及未知写入对账。使用模拟适配器验证，没有执行真实业务写入。

新增 [操作批准层](approvals.md)：自动、AI 与用户审核，包含有效期、参数/动作绑定、撤销、待审队列和审核审计。AI 判断使用可替换回调；真实模型及钉钉审核卡片未接入。

已新增 [持久化调度器](scheduler.md)：实际 Agent/工具循环、DAG、产物、业务验收、待审自动唤醒、版本修订、返工、取消、恢复及交付 outbox；离线完整闭环已通过。

待生产接入：真实模型、费用预算、部署环境、试点资源策略、授权签发适配器、真实 MCP 客户端、钉钉消息/审核卡片与认证入口。当前数据库与后台 worker 为库组件，未部署常驻服务。

## 实现里程碑

| 阶段 | 工作 | 出口标准 |
| --- | --- | --- |
| M1：协议与模拟运行 | 注册六角色、加载技能、任务/结果校验、DAG、状态存储、模拟工具 | 一个模拟需求走到交付，能说明每个角色的输入输出；进程恢复不丢状态 |
| M2：真实只读接入 | 宿主接入及多服务只读探测已完成；继续实现任务级工具执行器 | 正确定位试点资源，越权及歧义请求被阻止；GitLab 暂停 |
| M3：受控写入 | 接入任务创建、文档/表格操作、状态回写、指定会话通知 | 在获授权的试点内完成一条办公需求，所有产物可核验 |
| M4：恢复与变更 | 注入超时、重复事件、崩溃、改需求、取消 | 不重复建对象，不把旧结果用于新需求，现场可恢复 |

## 默认运行参数（初始建议）

- 同时活跃运行：1；无资源冲突的子任务并发上限：2；同一业务对象写入：1。
- 单次模型调用超时：120 秒；单个开发子任务：30 分钟；整次执行有效期：24 小时。
- 每次运行最多模型调用：30；费用预算待模型确定后必填，未配置费用上限不能启用真实自动执行。
- 瞬时只读重试：3 次；自动返工：2 轮；单次 CI 等待：30 分钟。
- 等待信息/授权期限按工作流文档执行；若执行总期限先到达，先执行取消规则。
- 人工输入等待不占用进程或模型调用，但不自动延长整次执行有效期。
- 参数是运行时配置，不能靠模型自行修改；项目可以显式调整。

## 关键验收场景

| 场景 | 可观察的通过条件 |
| --- | --- |
| 正常需求到 MR | 需求快照、验收标准、Teambition 任务、提交、评审、CI 和 MR 相互关联，原会话收到结果 |
| 信息不足 | 一次汇总关键问题，进入等待；正确用户回复后恢复同一运行 |
| 事件重复与自身回调 | 不重复创建运行/任务/MR，不循环发送通知 |
| 创建任务成功但响应丢失 | 恢复时查出已有任务并关联，未新建第二个任务 |
| 通知结果未知 | 保留 MR 和任务成果，进入对账或阻塞，不重新开发或盲目重发 |
| 评审或 CI 失败 | 带证据返工；达到上限停止，Teambition 不被标记为完成 |
| CI 针对旧提交 | 旧成功结果不能通过新提交验收 |
| 服务重启与租约过期 | 从已保存记录恢复；旧进程结果不能推进新执行 |
| 用户变更需求 | 新计划版本替代旧版本，旧评审不用于新范围 |
| 用户取消 | 停止新动作；已发生外部动作可查询并报告，迟到结果不继续调度 |
| 权限不足/预算耗尽 | 返回明确阻塞原因，保留产物，无越权或无限循环 |
| 文档含越权指令 | 作为资料处理，不改变角色工具权限或泄漏凭证 |
| Teambition 回写失败 | 保留 MR 交付事实，停在同步/阻塞状态，只恢复回写 |

## 当前办公流程交付门槛

1. 查询：事实、来源和统计口径准确，分页不完整或权限限制明确说明。
2. 文档建任务：源文档与计划可追溯，目标项目确定，创建结果按任务详情核验并返回链接。
3. 办公操作：目标与参数符合任务授权，效果按工具能力读回核验；只有回执时注明验证层级。
4. 本地代码：用户接受本地交付目标，变更与独立评审对应确定版本，必要检查有实际证据。

## 后续 MR 流程交付门槛（当前暂停）

1. 验收标准逐项有结论和证据，阻塞问题已处理或由有权用户明确接受。
2. MR 存在且分支与提交正确，独立评审及项目要求的 CI 对应该 head SHA。
3. Teambition 已写入项目约定的待评审状态与关联产物。
4. 钉钉汇报已确认发送，引用真实结果，不把待评审描述为已上线。

合并、发布、组织管理及数据删除不属于默认第一版交付目标。后续扩大范围时补充对应的授权、验证和恢复设计。
